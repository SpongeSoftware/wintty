---
title: Contributing
description: How to contribute to wintty.
---

Use [Conventional Commits](https://www.conventionalcommits.org) for every commit and PR title. Versions come from git tags (`vX.Y.Z`); releases are produced by GitHub Actions with SBOMs (Syft) and changelogs (git-cliff).

See `CONTRIBUTING.md` in the repository for the full guide.
