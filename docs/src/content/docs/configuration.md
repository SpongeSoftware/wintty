title: Configuration
description: wintty configuration reference.
---

Configuration lives at `%APPDATA%\wintty\config` and uses Ghostty-style `key = value` lines. Changes are applied on save.

```ini
font-family = Cascadia Mono
font-size = 12
cursor-style = block
scrollback-limit = 10000
command = pwsh.exe
```
